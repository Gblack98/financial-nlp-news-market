# Financial NLP — News Sentiment & Market Movement Prediction

Predict stock market direction from financial news:
- **FinBERT** (BERT pre-trained on financial texts) for sentiment analysis
- **Technical indicators**: RSI, MACD, Bollinger Bands
- **Multivariate LSTM** fusing sentiment + price features
- Simple signal-based backtest
